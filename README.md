# hive-hub-mcp

A read-only MCP server for the public Hive Hubs. It lets any AI app browse organization seeds, resolve a
seven-word chant, and pull down a seed's archive with its SHA-256 checked. One file, Python 3.9+ standard
library, no dependencies.

**Set it up from your AI app:**
- RAPP Hive Hub (RAPP Work organization seeds): https://kody-w.github.io/rapp-hive-hub-join/
- Hive Hub (the protocol-neutral core): https://kody-w.github.io/hive-hub-join/

| Tool | What it does |
| --- | --- |
| `list_seeds(hub?, query?)` | Seeds on both hubs: name, tagline, chant, team counts, page |
| `get_seed(slug, hub?)` | One seed's verified summary: mission, teams, tasks, files, first engagement |
| `resolve_chant(chant, hub?)` | Candidates for a seven-word chant (never unique authority) |
| `download_seed(slug, hub?, dest?)` | Saves the seed's `.zip` to `~/HiveSeeds/<hub>/<slug>/` after checking its SHA-256 and size |
| `get_skill(hub?)` | The hub's global skill, for joining and contributing with approvals |

Safety model: it only reads public URLs. It verifies every content-addressed document before using it.
It never extracts or runs anything it downloads, and it never writes anywhere except the chosen seeds folder.
A seed is a starter package, not an activated organization or running agent.

Try it without an AI: `python3 hive_hub_mcp.py --version`. Pages generated by
[kody-w/ai-setup-pages](https://github.com/kody-w/ai-setup-pages).
